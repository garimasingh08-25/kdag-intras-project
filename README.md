# kdag-intras-project

AGRI BASED PROJECT:
CROP - TO - CREDIT INCOME PREDICTION

Engineered a scalable machine learning pipeline to forecast the annual income of 40,000+ farmers, bridging the gap between raw agricultural data and FinTech credit risk assessment. The predictive engine enables data-driven financial profiling by assessing economic resilience through spatial-temporal climate, infrastructure, and socio-economic indicators. The model architecture includes advanced feature engineering and a trimodel ensemble
